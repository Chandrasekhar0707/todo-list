# 📝 To-Do List Web App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. This app helps users manage daily tasks efficiently with a clean and user-friendly interface.

## 🚀 Features

* ➕ Add new tasks
* ❌ Delete tasks
* ✅ Mark tasks as completed
* 💾 Data stored in browser (Local Storage)
* 📱 Responsive design (works on mobile & desktop)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🌐 Live Demo

👉 https://Chandrasekhar0707.github.io/todo-list/

## 📂 Installation & Usage

1. Clone the repository:

   ```bash
   git clone https://github.com/Chandrasekhar0707/todo-list.git
   ```
2. Open `index.html` in your browser
